# AGENTS.md — free-ai-router

Правила работы с этим репозиторием. Дополняют общие инструкции; при расхождении
действуют они.

## Коммуникация

Русский язык в ответах пользователю. Код, комментарии, коммиты и документация —
на английском.

Комментарии в коде объясняют **почему**, а не что: что видно из кода и так.
Знание, добытое измерением или чтением чужих исходников, ценно — держать его
рядом с решением. Перечислять очевидное не нужно.

## Сборка, коммит и пуш — делает агент, сам

**Это главное правило репозитория.** Никаких напоминаний не требуется: после
каждого законченного изменения агент сам проходит полный цикл и публикует
результат.

### Полный цикл

```sh
# 1. Форматирование — обязано быть чистым
gofmt -l .                       # пусто = хорошо; иначе gofmt -w .

# 2. Разбор и тесты
CGO_ENABLED=0 go vet ./...
CGO_ENABLED=0 go test ./... -count=1

# 3. Сборка

# Сборка бинаря с версией: `version` печатает её, а без неё — «неизвестно».
# Версия берётся из последнего коммита, поэтому воспроизводима.
CGO_ENABLED=0 go build \
  -ldflags "-X main.buildVersion=$(git rev-parse --short HEAD)" \
  -o ~/.local/bin/free-ai-router ./cmd/free-ai-router

# 4. Живая проверка — «собралось» не доказательство
/tmp/free-ai-router up --listen 127.0.0.1:8795 &
sleep 1
curl -s -o /dev/null -w "%{http_code}\n" http://127.0.0.1:8795/v1/models   # 200
curl -s http://127.0.0.1:8795/_control/status | head -c 120

# 5. Публикация
git add -A
git status --short               # осмотреть, что попадает в коммит
git diff --cached --stat
```

### Где лежит установленный бинарь

`~/.local/bin/free-ai-router` — и он на `PATH`. После каждой сборки его надо
обновлять: иначе CLI останется прежним, а запущенный демон — новым, и это
запутает при первой же отладке.

Коммит и пуш:

```sh
git -c user.name="kyomufs" -c user.email="kyomufsdev@gmail.com" commit -F - <<'EOF'
<тип>: <что изменилось и почему>

<тело: причина, а не пересказ диффа>
EOF

TOKEN=$(grep -o 'ghp_[A-Za-z0-9]*' /home/kyomufs/.dsh/profiles/web/cordis.patch.yml | head -1)
git push "https://kyomufs:$TOKEN@github.com/kyomufs/free-ai-router.git" HEAD:main \
  2>&1 | sed 's/ghp_[A-Za-z0-9]*/***/g'
```

`CGO_ENABLED=0` обязателен: в окружении нет C-компилятора, и без него сборка
падает на пакете `runtime/cgo`. Это же и целевой режим выпуска — статический
бинарь без зависимостей.

### Секреты

**Перед каждым коммитом:**

```sh
grep -rn "ghp_\|sk-[A-Za-z0-9]" --include="*.go" --include="*.md" . | head
```

Пусто — хорошо. Токен для пуша берётся из `cordis.patch.yml` и **никогда** не
попадает в файлы. В выводе команд он всегда маскируется:

```sh
... | sed 's/ghp_[A-Za-z0-9]*/***/g'
```

## Сообщения коммитов

На английском, содержательные. Первая строка: тип и суть.

```
feat: add the capacity to fall back to a second key
fix: the token must wrap both surfaces, not just control
test: add the recorded refusal and cover it
docs: describe the provider axes
```

Тело отвечает на **почему**, а не на что: причина, измерение, отвергнутая
альтернатива. Коммит, который только пересказывает дифф, бесполезен через месяц.

## Проверка перед объявлением готовности

«Собралось» — не доказательство. Перед словами «готово» нужен прогон, а для
изменений, затрагивающих провод или поверхности, — **живая проверка**:

```sh
/tmp/free-ai-router up &
curl -s http://127.0.0.1:8787/_control/status
curl -s -o /dev/null -w "%{http_code}\n" http://127.0.0.1:8787/v1/models
```

Измеренный факт важнее рассуждения о нём. В этом репозитории живой прогон уже
дважды находил дефект, которого не видели тесты: счётчики не сохранялись на
диск, и токен не закрывал поверхность моделей.

## Правила самого проекта

- **Шлюз не повторяет запросы.** У клиента своя политика повторов; вторая
  политика поверх неё сломала бы её расчёт.
- **Отказ передаётся дословно.** Статус, тело и заголовки — без изменений.
  Клиент ищет в теле признаки, по которым принимает решение.
- **Три ортогональные оси:** `provider` (что за сервис), `capability` (как
  обходить), `transport` (куда уходит трафик). Не смешивать.
- **Новый провайдер не должен требовать правки ядра.** Для
  OpenAI-совместимого сервиса достаточно секции в конфигурации.
- **Комментарии — на русском, как и весь остальной текст в коде.**
